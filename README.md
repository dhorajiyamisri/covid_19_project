## 📌 Project Overview

**COVID-19 Data Analysis & Visualization** is an interactive data analysis and visualization project built using **Python, Pandas, Matplotlib, and Streamlit**.

The project analyzes COVID-19 case and death data and converts the analysis into an interactive web dashboard.

The dashboard allows users to explore COVID-19 trends, country-wise statistics, summary metrics, and visualizations through a simple and interactive interface.

---

### 🌐 Interactive Streamlit Dashboard

The application is deployed using **Streamlit Community Cloud**.

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze COVID-19 case and death data.
- Perform basic exploratory data analysis.
- Understand country-wise COVID-19 statistics.
- Analyze daily COVID-19 trends.
- Visualize cumulative cases and deaths.
- Create an interactive dashboard.
- Provide easy-to-understand data visualizations.
- Deploy the dashboard as a live web application.

---

## 📊 Dataset

The project uses a CSV dataset containing COVID-19 case and death information.

### Dataset Columns

| Column | Description |
|---|---|
| `date` | Date of the observation |
| `country` | Country name |
| `new_cases` | Number of newly reported COVID-19 cases |
| `new_deaths` | Number of newly reported COVID-19 deaths |
| `total_cases` | Cumulative number of reported cases |
| `total_deaths` | Cumulative number of reported deaths |

### Dataset Information

- **Rows:** 60
- **Columns:** 6
- **Countries:** India and USA
- **File:** `covid_data_sample.csv`

> **Note:** The dataset included in this project is a sample dataset intended for data analysis and dashboard demonstration.

# 📈 Dashboard Features

## 1. 📊 COVID-19 Overview

The dashboard displays important summary metrics such as:

- Total Cases
- Total Deaths
- New Cases
- New Deaths

These metrics provide a quick overview of the selected COVID-19 data.

---

## 2. 🌍 Country Filter

Users can select countries from the sidebar to analyze specific country data.

Available countries include:

- 🇮🇳 India
- 🇺🇸 USA

The dashboard updates the displayed analysis based on the selected country.

---

## 3. 📋 Country-wise Summary

The dashboard provides country-level summary information including:

- Average New Cases
- Average New Deaths
- Average Total Cases
- Average Total Deaths

This helps compare the overall COVID-19 patterns between the available countries.

---

## 4. 📈 Daily New Cases

A time-series visualization is used to understand how newly reported COVID-19 cases changed over time.

---

## 5. 📉 Daily New Deaths

A time-series visualization shows the daily COVID-19 death trend.

---

## 6. 📊 Total Cases

The dashboard visualizes cumulative COVID-19 cases over time.

This helps understand the overall growth of reported cases.

---

## 7. 📊 Total Deaths

The dashboard also visualizes cumulative COVID-19 deaths over time.

---

## 8. 📄 Raw Data

The dashboard provides access to the filtered raw dataset so users can directly inspect the underlying records.
